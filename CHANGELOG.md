# Changelog

## 1.1.2

- First GitHub release, with a standalone source repository and downloadable macOS application.
- Explicit macOS 13 deployment target; earlier local builds inherited the build machine's macOS 26 target.
- Include installation, permissions, recovery, build instructions, architecture details, and third-party notices.

## 1.1.1

- Add the Finder-style HD Helper application icon.

- Integrate Shift-scroll zoom directly into Finder HD Helper.
- Pause the built-in scroll handler when LinearMouse is running.
- Preserve high-resolution previews, automatic wrapping, and launch at login.

## 1.0.3

- Use Finder's live sort menu and icon-size slider to keep thumbnails within the window width.
